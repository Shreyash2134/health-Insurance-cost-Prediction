# CHAPTER 3: PROPOSED SYSTEM

## Drawback Of Current System And Need of Proposed System
Traditional insurance pricing heavily relies on rigid and static actuarial tables. These older tables completely fail to capture the complex and non-linear relationships existing between multiple human health factors, such as how body mass index physically interacts with an individual's smoking status. Current systems additionally lack the computational ability to provide real-time, dynamic multi-year projections that accurately account for both medical inflation and compounding no-claim bonuses. Furthermore, corporate human resources departments face significant manual overhead when calculating premiums for hundreds of employees simultaneously, which ultimately leads to human error and severe inefficiency. The proposed system directly addresses these critical drawbacks by seamlessly integrating a robust machine learning inference engine with a dynamic actuarial pricing engine. It effectively utilizes a trained random forest regressor to accurately predict base medical costs. This entirely data-driven approach allows for precise dynamic risk adjustments, fully automated underwriting decisions, and the instant generation of transparent, multi-tier, multi-year insurance plans for both single individuals and large bulk enterprise uploads.

## System Description And SRS
The medical prediction system is an advanced insurtech web application specifically designed to automate complex health insurance pricing operations. It successfully allows individual users and enterprise human resource managers to rapidly input necessary demographic and health data via a standard web form or a bulk comma-separated values file. The backend server effectively preprocesses the incoming data and carefully feeds it into a pre-trained machine learning model to accurately predict anticipated future medical costs. An integrated actuarial engine then immediately applies specific risk multipliers, log-normal claim severity statistical simulations, and standard no-claim bonus logic to mathematically calculate final premium costs across three distinct tiers projected securely over up to twenty years. The primary software purpose is to provide highly accurate and artificial intelligence driven medical insurance premium calculations alongside instant underwriting decisions. The overall system scope covers individual predictive quotes and bulk corporate policy pricing, including long-term coverage projections factoring in standard twelve percent annual medical inflation rates.

## 3.3 System Analysis

### 3.3.1 System Architecture
The proposed system architecture strictly follows a highly modular and secure multi-tier architectural pattern. The initial presentation layer utilizes standard markup language templates to visually collect user data and cleanly display the final calculated tabular results. The intermediate controller layer features a lightweight web server application that successfully handles all internal routing, strict request validation protocols, and necessary data sanitization procedures. The core inference layer contains the machine learning module which utilizes powerful statistical libraries to execute rapid predictions via the serialized random forest predictive model. The subsequent actuarial layer acts as a robust mathematical calculation engine containing distinct sub-modules dedicated entirely for precise risk adjustment, base premium calculation, claim severity simulation, and advanced multi-plan generation. The final output layer operates as a dynamic result formatter that actively renders the responsive user interface components or structurally generates downloadable comma-separated value reports for enterprise bulk processing tasks.

### 3.3.2 Flowchart Of System
The detailed system flowchart clearly traces two distinct operational paths concerning single form inputs versus bulk file uploads that ultimately converge into one unified processing pipeline. Initial data flows directly from the user input interface through highly rigorous structural validation checks. Validated data is then mathematically encoded and systematically passed to the primary machine learning model to accurately predict the raw financial cost. The procedural flow continues securely into the risk adjustment module factoring specific diseases or alcohol consumption, which is immediately followed by a log-normal claim simulation and base premium calculation including standard government tax additions. Finally, the overall execution flow enters a comprehensive multi-year programmatic loop calculating annual inflation and cumulative bonus discounts over twenty years. The entire process logically ends with a strict score-based underwriting decision before branching out sequentially to either visual HTML rendering or downloadable enterprise CSV file generation.
