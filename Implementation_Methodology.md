# Implementation Methodology

The way we built the Medical Prediction System is by working in small, step-by-step stages, which allowed us to constantly improve the project as we went along. We divided the system into separate, easy-to-manage parts, so the website design, the background coding, and the math calculations are all handled independently. This smart organization means developers can test and fix one specific piece without breaking the rest of the website. By taking this organized approach, we made sure the core features were built correctly and tested thoroughly before putting everything together.

The background of the website is powered by Python and a tool called Flask, which safely handles all the information users type in. During development, we added a smart machine learning model that looks at a person's age, health, and habits to quickly predict their basic medical costs. Once the system guesses the base cost, our special math engine takes over to add in real-world insurance rules, like extra risks or discounts for staying healthy. This step-by-step background process is what turns a simple prediction into a fully complete, multi-year insurance plan.

The actual website pages that users see were created using simple HTML and CSS so they look great and are easy to use on any device. Before letting anyone use the system, we ran strict tests to make sure the math was perfect and the website wouldn't crash when calculating costs. We also made sure the system was strong enough to handle large companies uploading big files with hundreds of employees at once. Finally, the finished website was placed on a secure online server so people anywhere can access it easily through their internet browser.
